# Implementation Plans

Generated by the `improve` skill on **2026-06-24** from a full production-readiness audit
of `telegram-new` (React/Vite frontend `Telegram-premium-2025`, Node/TS backend
`telegram-premium-server`, plus orphaned Python scripts).

> **No version control:** this directory is **not a git repo**. Plans cannot use
> `git diff <SHA>` for drift detection. Each plan instead includes **"Current state"
> code excerpts** — the executor must open the cited file and confirm the live code
> matches the excerpt before proceeding. A mismatch is a STOP condition.

> **Hard precondition for the whole set:** the audit found **live credentials** committed
> in `telegram-premium-server/.env` and hardcoded in two `src/*.ts` scripts. Plan **001**
> (rotate + stop leaking secrets) should be actioned **first and out-of-band**; it is the
> only plan that is partly an ops runbook rather than a code change.

## Dependency notes

- **001 before 003**: 003 changes the JWT secrets; the leaked values must be rotated
  (001) so 003 sets *new* distinct secrets, not the burned ones.
- **006 before 015 / 020**: transaction work and god-object extraction are high-risk
  refactors; characterization tests from 006 are the safety net. Treated as hard deps.
- **008 before 021**: 021 extracts the shared highlight helper into one place; 008 first
  makes that helper *safe*, so 021 dedupes a correct implementation rather than a vulnerable one.
- **001 before 023**: 023 deletes committed log files / dead scripts; 001 already scrubs
  the hardcoded creds those scripts contain — do 001 first so secrets are rotated before
  the files are touched/removed.

## Findings considered and rejected (do not re-audit)

- **Decoy adaptive-delay array indexing** (`decoyBot.service.ts:678-685`): the slice math is
  correct on inspection; only the variable naming is confusing. Not a bug — naming nit, skip.
- **"Design docs read as prompt-injection"**: root `*.md` planning docs containing imperative
  language is normal documentation, not an injection vector. Not a finding.
- **`ip` package SSRF CVE**: `ip` is imported only in `system.util.ts` for `getLocalIP()` log
  output, never for a security decision. Downgraded to LOW/no-op; covered as a removable dep in 019.
- **`xss()` vs `cors()` middleware ordering** in `app.ts`: no real security impact; the real
  action (replace abandoned `xss-clean`) is in 019.
- **decoy client `refCount` "init to 0" bug (M15)** (`decoyBot.service.ts:905-948`): on direct
  read the lifecycle is correct — the inflight sets `refCount: 0`, then each acquirer does
  `refCount += 1` after `await inflight`, so a single acquirer ends at 1 and N concurrent
  acquirers sharing one inflight end at N. Brittle to read, but not a defect. No plan 018.
